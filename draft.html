Which mark goes in the search result

Rendered at the sizes that decide it, and dropped into a result row next to the description Google is already showing. Everything reads fine at 48, so the 16px column is the question — and between B and C it is really the two rows below it, because they split: one wins on white, the other on dark.

The part that is not a choice

All 29 pages ship the icon as data:image/svg+xml,… inlined in the href. That paints a browser tab correctly, which is why it has never looked broken. But Google fetches a favicon as its own URL, and a data: URI is not one — so there is nothing to fetch and the result gets the generic globe.

The fix is real files at real paths, regardless of which option wins below.
