People page — five layouts

Same five people in every one, so the only thing changing is the layout. Tell me a letter. You can mix — "C's grouping with D's density" is a fine answer.

A

Roomier list

What's there now, with the squeeze taken out: bigger avatars, real space between rows, and group headings that look like headings instead of tiny grey captions. The smallest change — same page, easier to read.

B

Cards

Each person is a card with the action at the bottom. Feels like browsing people rather than reading a table, and looks deliberate when there are only four or five of them. Gets long once there are thirty.

C

Grouped panels

Each group is its own card with a proper header and a count. The strongest answer to "on your path looks too narrow" — a group is a container rather than a label floating above some rows.

D

Table

Columns, aligned, scannable down the page. The best of these at forty people and the coldest at four. Everything lines up, which is what makes the current version feel ragged.

E

Closest match, then the rest

The best match gets a real card with the facts spelled out; everyone else is a quiet list underneath. Turns the page into a recommendation instead of a directory — which is what someone actually wants on their first visit.
