What changed, and why

  • "Profile" is gone. It was a second link to the place the name already went, and the word repeated down the whole page — six rows, six times, saying nothing about anybody. The face and the name are the link now, which is where people press anyway. Hovering underlines the name so it is clear it can be pressed.
  • Every action is the same width. They were already the same height, but "Send request", "Partners" and "Asked" are different lengths, so the right edge zig-zagged. A minimum width fixes the box and centres the short labels inside it.
  • One action per row. With the profile link gone there is exactly one thing to press per person, so there is no question about which button is the important one.

Still open

Worth deciding before this ships

Losing the word "Profile" makes the row cleaner but slightly less obvious on a first visit — the hover underline is the only hint, and there is no hover on a phone. Tapping a name to open a profile is a common pattern, so I think it is worth it, but say if you would rather keep a small chevron at the end of the person block as a permanent signpost.
