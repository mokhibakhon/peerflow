Six chat layouts you already know

Each one is the pattern a well-known app uses, rebuilt in PeerFlow’s colours rather than copied in their blue — what changes is where the name sits, whether there are bubbles, and how tight it is. Same six messages, same header and composer everywhere. None of these is what’s live now. Say a letter.

A

Bubbles with tails

WhatsApp, Telegram

Tinted ground, small bubbles with a tail, the time and ticks tucked on the last line, almost no gap between messages. The layout more people have used than any other.

Flat rows with names

Slack

No bubbles at all. Square avatar, bold name, time, message — and when the same person writes twice in a row the second one drops the name. Densest of the six, and the easiest to read back weeks later.
